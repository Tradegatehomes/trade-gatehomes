# Admin listing management

## Goal
Give staff a practical way to add and maintain property listings from the admin area, beyond the existing quick pricing and status controls.

## Work
- Add a staff-only property creation form for core listing details and pricing; new listings start as drafts.
- Add an edit flow for listing descriptions, location, property type, guest/room counts, pricing, house rules, and cancellation policy.
- Let staff add and remove property photo URLs and select the primary photo.
- Keep writes under the existing staff role and row-level access rules; do not change database structure.
- Verify listing operations and update the roadmap with remaining incomplete features.

## Not included
Payment processing, transactional messaging, role assignment, and guest self-service changes remain separate work.
